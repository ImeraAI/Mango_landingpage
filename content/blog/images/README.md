# Blog pictures

Every picture used by every blog post lives in this one folder. Upload yours
here, then write **just the filename** in your post — no folders, no slashes:

```
image: dispatch-board.jpg
```

```
![A dispatcher looking at the schedule board](dispatch-board.jpg)
```

Naming: lowercase, hyphens instead of spaces, and say what the picture actually
shows — `dispatch-board.jpg`, not `IMG_4821.JPG`. Every post shares this folder,
so a name like `hero.jpg` will collide with someone else's.

Use `.jpg` for photographs and `.png` for screenshots. Aim for about 1600 pixels
wide and under roughly 500 KB.

Full instructions are in [the README one folder up](../README.md).
